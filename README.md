# Bora Bora — доставка

Сайт доставки ресторана Bora Bora (Солнечнодольск, ул. Набережная, 17).
Пицца 30 см, закуски, авторские лимонады, комбо-наборы.

## Что это

Одностраничный статический сайт без сборки и зависимостей: `index.html`
содержит всю вёрстку, стили и логику. Фотографии лежат в `img/`.

Свёрстан **только под мобильные** — колонка 480 px, на десктопе
показывается по центру экрана.

## Как заказ доходит до ресторана

Корзина собирает текст заказа и открывает мессенджер с уже готовым
сообщением. Каналы: MAX, WhatsApp, SMS, звонок, копирование в буфер.
Серверной части нет — заказы приходят в чат администратора.

## Что менять

Всё настраивается в блоке `CONFIG` в начале `<script>` в `index.html`:

- `phoneRaw` / `phoneText` — телефон для звонков и мессенджеров
- `address`, `mapUrl` — адрес и точка на Яндекс.Картах
- `hours`, `hoursText` — часы приёма заказов (от них зависит бейдж
  «Открыто / Закрыто» и предупреждение в корзине)
- `delivery` — минимальная сумма, цена доставки, порог бесплатной
  доставки, время и зона
- `social` — ссылки на соцсети в подвале, пустая ссылка убирает иконку
- `channels` — какие способы отправки заказа показывать

Меню лежит ниже в массиве `MENU`. Комбо-наборы — первая категория,
у них есть `options` с выпадающими списками выбора начинки.

## Деплой

Статика, сборка не нужна. Любой хостинг статики отдаёт папку как есть.
На Vercel определяется как Framework Preset: **Other**.
